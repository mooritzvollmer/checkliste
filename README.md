# Checkliste Web-Barrierefreiheit

Interaktive Checkliste für einen strukturierten ersten Blick auf Anforderungen der WCAG 2.2 in den Konformitätsstufen A und AA.

**Live:** [checkliste.moritzvollmer.de](https://checkliste.moritzvollmer.de/)

## Funktionen

- Prüfpunkte nach Themenbereichen
- verständliche Hinweise und sichere Empfehlungen
- aufklappbare Detailinformationen
- gespeicherter Arbeitsfortschritt im Browser
- responsive, tastaturbedienbare Oberfläche

## Technische Basis

Vanilla JavaScript, CSS und Vite.

```sh
npm install
npm run dev
npm run build
```

Ein Projekt von [Moritz Vollmer](https://moritzvollmer.de/).
